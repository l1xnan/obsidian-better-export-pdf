# 来自 Issue 的问题

## 预览和 PDF 不一样

HTML 预览是连续的一页，没有分页。PDF 有分页。2.0 另外提供 PDF 预览，两者仍可能有细微差别。见 [限制](limits.md)。

不想反复试图片大小时，用 `<img>` 指定尺寸。见 [样式、背景与分页](style.md#分页)。

## 标题和作者没有印在页面上

`title` 和 `author` 是 PDF 的文档属性，不是页面上的文字。要显示出来，写在页眉或页脚里。见 [页眉页脚与元数据](header-footer.md#pdf-元数据)。

## 怎样改字体或背景？

加一段只在打印时生效的 CSS，并使用 Obsidian 的字体变量。单独写 `font-family` 经常被主题盖掉。这段 CSS 里的背景色，要打开 `Print background` 才会进 PDF。见 [样式、背景与分页](style.md)。

导出对话框里的片段列表，只列出尚未在 `外观 > CSS 片段` 中启用的片段。

## 怎样分页？

插入 `<div class="break-page"></div>`，或用 CSS 把分隔线变成分页。合成一份 PDF 时，也可以让每篇笔记另起一页。见 [分页](style.md#分页)。

## 文件夹导出的顺序不对

`Export folder to PDF` 按文件名排序，不按文件列表里的顺序。要自己定顺序，写一篇 `toc: true` 的笔记，导出这篇笔记，不要导出文件夹。见 [文件夹导出](folder.md)。

## 可以不打开对话框就导出吗？

可以。Obsidian CLI 导出一篇笔记，不打开预览，也不弹出保存窗口。它不导出文件夹。见 [命令行](cli.md)。

## 怎样把一篇笔记打成一长页？

**Page Size** 选 `Custom`，**Margin** 选 `None`，再自己填页面尺寸。预览里的尺寸提示只是估计。见 [导出为一页](export.md#导出为一页)。

## YAML 或属性出现在 PDF 里

这个插件不打印 YAML 块。如果属性出现了，检查 Obsidian 的「文内属性」设置。其他插件也可能把这段内容插进来。
