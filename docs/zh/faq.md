# 常见问题

## 边距改了，下次又回去了

在对话框里改边距时，插件不会立刻写入配置。要点 `Export`，或按 `Enter` 完成一次导出，这次的边距才会在下次打开时还在。说明见 [导出一篇笔记](export.md)。

## 预览和 PDF 不一样

HTML 预览把笔记画成连续的一页，用来看大致版式，所以没有分页线。分页以 PDF 为准。2.0 可以在对话框里切换到 PDF 预览，先看分页再导出。两处是分别渲染的，细小差别见 [限制](limits.md)。

图片大小不好把握时，用 `<img>` 写上宽高，见 [分页](style.md#分页)。

## 标题和作者没印在纸上

frontmatter 里的 `title` 和 `author` 会写进 PDF 的文档属性，阅读器的「文档属性」里能看到，页面正文里没有这两行。要印在纸上，把文字放进页眉或页脚，见 [页眉页脚与元数据](header-footer.md#pdf-元数据)。

## 字体或背景没变

打印样式写在 `@media print` 里，并改 Obsidian 提供的字体变量。只写一条 `font-family` 时，主题里更具体的规则经常会盖住它。背景色还要打开 `Print background` 才会进 PDF。做法见 [样式、背景与分页](style.md)。

导出对话框里的 `CSS snippets`，只列出尚未在 `外观 > CSS 片段` 中启用的片段。已经全局启用的片段不在这个列表里。

## 怎么分页

在笔记里插入 `<div class="break-page"></div>`，再用 CSS 规定它在打印时换页。也可以把分隔线 `hr` 设成换页，这样就不用在正文里写 HTML。合并成一份 PDF 时，还可以让每篇笔记结束后另起一页。示例见 [分页](style.md#分页)。

## 文件夹顺序不对

右键文件夹的 `Export folder to PDF` 按文件名排序，不按文件列表里排好的顺序。要自己指定顺序，写一篇带 `toc: true` 的笔记，然后导出这篇笔记。见 [文件夹导出](folder.md)。

## 不想弹出对话框

用 Obsidian 的命令行。它按上次保存的配置导出一篇笔记，不打开预览，也不弹出保存窗口。见 [命令行](cli.md)。

## 打成一长页

**Page Size** 选 `Custom`，**Margin** 选 `None`，再自己填页面宽高。预览里的尺寸提示只供参考。见 [导出为一页](export.md#导出为一页)。

## PDF 里出现了属性

这个插件不会把 YAML 原文打进正文。如果页面上仍然能看到属性，先看 Obsidian 是否打开了「文内属性」，再看其他插件有没有把属性块插进预览。
