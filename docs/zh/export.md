# 导出一篇笔记

1. 选择导出目标：
   - 在当前 Markdown 视图的右上角，点击更多选项，选择 `Better Export PDF`；
   - 打开命令面板，选择 `Better Export PDF: Export Current File to PDF`。
2. 在弹出对话框中，修改相关配置。
3. 点击 `Export`，选择导出路径。如果不修改配置，可以直接按 `Enter` 键导出。

同一个对话框里打开 **Landscape**，按横向打印。

## 导出为一页

在导出对话框中，**Page Size** 选择 `Custom`，**Margin** 设置为 `None`，再按文档内容设置页面尺寸。预览里的尺寸提示只是估计，不是最终印出来的高度。没有一个开关会量出笔记高度再自动填上。
