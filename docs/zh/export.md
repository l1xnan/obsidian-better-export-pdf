# 导出一篇笔记

可以从两个地方打开导出对话框：

1. 当前笔记右上角，点更多选项，选择 `Better Export PDF`。
2. 打开命令面板，运行 `Better Export PDF: Export Current File to PDF`。

在对话框里改好纸张、边距等选项，点 `Export`，再选一个保存位置。这次如果不用改配置，对话框打开后直接按 `Enter` 就能导出。

对话框每次打开，会带上上次导出时保存的配置。纸张、边距、缩放，以及对话框里的其他选项，都是在点 `Export` 或按 `Enter` 时写入的。只是打开看看、改了几项然后关掉，这些改动不会留下来。

勾上 **Landscape** 后按横向打印。

## 导出为一页

把整篇笔记打在一页上时，**Page Size** 选 `Custom`，**Margin** 选 `None`，再按内容填上宽高。预览旁边的尺寸只是估计，PDF 使用你填的宽高。
