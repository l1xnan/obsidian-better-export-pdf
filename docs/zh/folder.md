# 文件夹导出

一次导出很多笔记时，可以在 `插件设置 > 限制并发数` 里调整同时渲染的篇数，默认是 `5`。机器比较慢时，把这个数调小。

## 合成一个 PDF

在文件列表里右键文件夹，选择 `Export folder to PDF`。文件夹中的 Markdown 按文件名排序，合成一个 PDF。你在文件列表里拖好的顺序不会被用到。

## 每篇各一个 PDF

右键同一个文件夹，选择 `Export to PDF...`，再选择 `Export each file to PDF`。每篇笔记各生成一个 PDF。

## 按链接顺序

想按自己写的顺序合并时，新建一篇笔记，并打开 `toc`：

```markdown
---
toc: true
---

## 目录

[[笔记1|标题1]]
[[笔记2]]
[[笔记3]]
```

对这篇笔记使用 `Better Export PDF`。导出结果里，目录页在最前面，后面依次是笔记1、笔记2、笔记3，目录页上的链接可以跳到对应笔记。

不要对文件夹使用 `Export folder to PDF` 来读这份目录。那个菜单只按文件名排序，不会看笔记里的 `toc`。

合在同一份 PDF 里之后，某一篇正文里指向另一篇的链接，例如 `[[笔记2#标题]]`，还不会变成 PDF 内部跳转。同一篇笔记里的 `[[#标题]]` 可以跳转。
