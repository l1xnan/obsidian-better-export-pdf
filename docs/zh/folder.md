# 文件夹导出

多文件导出时，可以在 `插件设置 > 限制并发数` 里调整渲染阶段的并发数量。默认是 `5`。

## 合成一个 PDF

在文件列表中右键文件夹，选择 `Export folder to PDF`。文件夹里的 Markdown 会按文件名排序，导出成一个 PDF。文件列表里的排列顺序、以及文件名前面的数字，都不会被采用。要自己定顺序，用下面的 `toc: true` 笔记。

## 每篇笔记各一个 PDF

在文件列表中右键文件夹，选择 `Export to PDF...`，再选择 `Export each file to PDF`。

## 按链接顺序导出

新建一篇带 `toc: true` 的笔记，按顺序列出要包含的笔记：

```markdown
---
toc: true
---

## 目录

[[笔记1|标题1]]
[[笔记2]]
[[笔记3]]
```

对这篇笔记使用 `Better Export PDF`。导出顺序是当前目录页、笔记1、笔记2、笔记3。目录页里的链接可以跳转。不要对这篇笔记使用 `Export folder to PDF`：那个菜单按文件名排序，不会读 `toc`。

被包含的笔记里如果写了指向另一篇笔记的链接，例如 `[[笔记2#标题]]`，不会变成 PDF 内部跳转。同一篇笔记里的标题链接，例如 `[[#标题]]`，可以跳转。
