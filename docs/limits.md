# Limits

- The CLI exports one note at a time. To merge a folder, or to export each file on its own, use the file-explorer menu.
- The HTML preview is one continuous page for checking the layout. It has no page breaks. Use the PDF preview for pagination. The PDF is rendered again at export time, so the preview and the file can differ in small ways.
- `title` and `author` are stored in the PDF document properties. To show them on the page, put them in the header or footer.
- Exporting a folder from the file explorer sorts by file name. In the merged PDF, a link from one note to another is not yet an internal jump.
